# A11b successor content-free receipts

These eight JSON files preserve the aggregate, content-free receipts from two
independent clean-root builds (`c` and `d`) of the fresh successor source and
development corpus. The paired files must remain byte-identical.

They intentionally exclude packets, prompts, answers, gold rows, raw FHIR
bundles, and patient identifiers. They do not authorize a model call or open
the reserved efficacy split.
